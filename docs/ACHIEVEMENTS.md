# 日本旅遊成就

首頁足跡地圖下方顯示三個成就面板；桌面三欄、手機單欄，以原生 details/summary 展開全部項目。面板不受行程卡片篩選影響。每個已對應項目可連回原行程。

## 計算規則

- 同一地點只計一次；保留所有對應行程。已達成優先於已規劃，已規劃優先於待確認。
- 僅日本行程參與。只有 `status: "旅遊回憶"` 且 `dateEnd` 早於日本當日才計入達成數。
- 日期在今日或未來：已規劃。缺日期、日期無效或日期已過但仍標為預定：待確認。
- 成就與首頁原有「依日期自動顯示旅遊回憶」的標籤用途不同；成就不把單純日期經過當作已完成證據。
- 都道府縣必須有實際景點或住宿證據；不計轉機、途經。東京迪士尼計千葉，不把東京地區行程全算東京都。
- 名城採日本城郭協會日本100名城與續日本100名城，共 200 城，造訪即可，不要求集章。每日行程也可作證據。
- 星野只計住宿；用餐、參觀、雲海平台不等於入住。TOMAMU 未知 Tower 或 RISONARE 時不猜測；使用者已確認 2024 年入住 The Tower。
- 日期、狀態、或證據內容改變會重新計算。證據原文不存在時列待確認，不沿用已達成。

## 資料與維護

- `data/achievement-catalog.js`：47 都道府縣、200 名城、69 間日本星野住宿設施的固定快照，更新日期 2026-10-19。保存名單來源及官方連結；僅使用官方名稱、位置等事實資料，未轉載介紹文。
- 名城來源：https://jokaku.jp/business/great-castles/
- 星野來源：https://hoshinoresorts.com/en/hotels/ 、https://hoshinoresorts.com/ch/hotels/
- 星野排除海外及日歸設施；英語目錄補充中文目錄未列的 BunkLodge NEKOMA。虹夕諾雅飛鳥預計 2027-07-22 開業，不列入本期分母。來源：https://hoshinoresorts.com/jp/cards/1xzx0sp9mckz/
- 這是名單快照，不會因日期經過自動增減分母。新增、關閉、改名或開業需重新核對官方目錄後更新，保留同一實體設施的穩定 ID。
- `data/achievement-visits.js`：逐團建立明確對應。每筆 evidence 包含 `id`、`kind`（spot、day、stay）、`text`（來源原文）；不得依區域標題或模糊關鍵字自動點亮。
- 新增日本行程也須新增對應；漏建時面板列「尚未建立成就對應」。更改路線時檢查是否有新地點需要加入；既有原文不變不代表整趟路線已重新審核。
- 確認行程已完成後，更新原行程 `status` 為 `旅遊回憶`；不要僅因日期已過就代替使用者確認。TOMAMU The Tower 已建立精確 stay 證據並移除待確認備註。
- 使用者的最新決定優先；本次依使用者確認更新三團狀態及 TOMAMU 住宿館別，行程圖維持原版本。
